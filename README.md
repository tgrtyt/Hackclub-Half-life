I am building the tutorial starbie in order to learn more about PCB destign and building. I'm build ing my starbie in the shape of a controller. I designed my own little caracter (40x40 pixels) with it's own animations you can see a small picture of it above the PCB screenshot or look at all of the png:s uploaded in the main branch. For the controlls i used the default ones but i attatched my own animations. The starbie has 2 buttons for interaction with menues, a temperature/humidity sensor for sensing the enviroment, a gyro sensor that also lets you interact with the chatacter to make the starbie more imersive. There is also a 0.96 oled distplay for displaying the character and menues and lastly the esp 32 that controlls everything. For a full parts list please look at the BOM.
